# Ролик SEO Jarvis v2 — общие правила для исполнителей сцен

Ролик собирается кодом: HTML-страница 1920×1080, кадр = функция `seek(t)`, рендер Playwright кадр за кадром.
Ты делаешь **одну сцену** — один файл `film2/scenes/sN-*.js`. Остальные сцены делают другие исполнители параллельно.

## Что нельзя
- Нельзя менять `core.js`, `core.css`, `main.js`, `index.html`, чужие сцены. Нужен общий помощник — напиши его у себя в файле; если без правки ядра никак — напиши об этом в отчёте.
- Нельзя `setTimeout`, `setInterval`, CSS `transition`/`animation`/`@keyframes`, `Math.random()` без seed, `Date.now()`. Состояние кадра зависит **только от t**. Любой кадр можно запросить в любом порядке.
- Нельзя добавлять от себя тексты, цифры, персонажей, маскота, чужие логотипы. Только то, что написано в задаче сцены.
- Не коммитить в git.
- Не подсматривать старый ролик `film/` и `deliver/` — это НЕ образец.

## Контракт сцены
```js
(function () {
  injectCSS(`/* стили только с префиксом сцены, например .s4 ... */`);
  let R = {};                       // ссылки на элементы
  SCENES.add('s4', {
    dur: 4.4,                       // длительность, секунды (дана в задаче, не менять)
    build(root) { /* создать DOM внутри root (root = .scene.s4, 1920×1080, прозрачный). Можно измерять rectOf() */ },
    seek(t) { /* выставить ВСЁ состояние кадра для локального времени t ∈ [0, dur] */ },
  });
})();
```
- `root` прозрачный, под ним общий белый фон (`#bg`, как в ролике Gemini: белый центр, лёгкая серая виньетка) и сетка точек `#bg-dots` (включается в main.js, сам не трогай).
- `seek(t)` должен выставлять каждое анимируемое свойство на каждом кадре (не полагаться на прошлый вызов).
- Если сцена начинается/кончается «пустым кадром» — это значит в root ничего не видно (opacity 0), виден только общий фон.

## Что есть в ядре (`core.js`, всё глобально)
- `clamp, lerp, prog(t,a,b)` (0..1), `E.*` — сглаживания: `outCubic, inOutCubic, outQuart, outExpo, inExpo, inOutExpo, inCubic, outBack, springSoft` (пружина с лёгким перелётом).
- `tween(t, [[t0,v0],[t1,v1,ease?],...], ease)` — значение по ключам. `bump(t, a, d)` — 0→1→0 (синус) за d секунд с момента a.
- `rng(seed)` — детерминированный random.
- `el(tag, cls, parent, html)`, `injectCSS(css)`, `rectOf(node)` → {x,y,w,h,cx,cy} в координатах кадра (мерить в build, пока нет transform), `px(v)`.
- `logoSVG()` — знак логотипа SEO Jarvis (синий скруглённый квадрат с белым «вихрем»), SVG-строка.
- `makeCursor(parent)` → `c.set(x, y, {press:0..1, opacity, ring:0..1})` — курсор macOS, (x,y) = кончик стрелки. `ring` — круг-отклик при клике (растёт и гаснет, 0→1 за ~0.35 с).
- `path2(t, [[t,x,y],...])` — траектория курсора.
- `splitWords(node, text)` + `revealWords(words, tLocal, {stagger, dur, dx, blur, skew})` — **эффект появления слов как в ролике Spotify** («Collect what you love»): слова по очереди слева направо выходят из прозрачности и размытия со сдвигом вправо и лёгким курсивным наклоном. `hideWords(words, tLocal)` — обратный уход.
- `typed(str, t, start, cps)` — набор текста по символам.
- `makeHeadline(parent)` — заголовок «Всё для продвижения / в одном кабинете» (две строки, центр кадра). Только для сцен 2 и 3.
- `LAPTOP` — параметры макета MacBook (только сцена 1).
- Классы `core.css`: `.app-card .app-h1 .app-sub .app-label .app-field(.focus) .ph .app-hint .app-btn(.solid) .app-btn-ghost(.hover) .caret .an-pill .headline .logo-word`. Токены цвета: `--blue #1A69F0`, `--ink #1C2233` (основной текст — тёмный, но не чёрный), `--ink2 #5A6275`, `--ink3 #8B93A5`, `--line #E3E8F0`.

## Стиль движения (планка — продуктовые ролики Apple/Google/Figma)
- Всё быстро и плавно: появления 0.3–0.6 с, `outCubic/outExpo/springSoft`. Никаких линейных движений, кроме вращения спиннера.
- Камера — это обёртка `div` со `transform: translate(...) scale(...)`, плавные наезды `inOutCubic`/`inOutQuart`.
- Быстрые пролёты (иконки, плашка улетает) — с имитацией размытия в движении: `filter: blur()` пропорционально скорости + лёгкое растяжение вдоль движения (`scaleX` 1.1–1.3 при горизонтальном полёте). В покое — без размытия.
- Клик: курсор `press` 0→1→0 за ~0.18 с, у нажатой кнопки `scale(0.96)` и обратно, `ring` от момента клика.
- Шрифт Inter (`font-family` наследуется). Цвет текста на белом — `var(--ink)`, не чистый чёрный. Проверяй контраст: светло-серый текст мельче 16 px не использовать.
- Ровность: всё, что должно быть по центру, — ровно по центру (проверяй `rectOf` и по скриншоту), одинаковые отступы, никаких наложений и обрезанных краёв (кроме намеренного вылета за кадр).

## Как смотреть результат
Сервер уже запущен: `http://127.0.0.1:8765/film2/index.html?scene=s4` (если не отвечает — из корня репозитория: `python3 -m http.server 8765 --bind 127.0.0.1 &`).
Стоп-кадры и лист кадров (из папки `film2`):
```bash
SCENE=s4 node tools/snap.mjs snaps/s4 0.5 0 0.3 0.6 1.0 1.5 2.0 2.5 3.0 3.5 4.0 4.4
```
→ `snaps/s4/tNN.NN.png` и `snaps/s4/sheet.png`. Масштаб 0.5 — для листа; для проверки мелочей снимай отдельные кадры с масштабом 1.
Смотри кадры инструментом Read (он показывает картинки). Ошибки JS печатаются как PAGEERROR — их быть не должно.
Проверка скорости и плавности: сними кадры каждые 0.1 с на ключевых движениях — не должно быть рывков и «телепортов».

## Петля качества (обязательно)
Рендер → лист кадров → оценка каждого ключевого момента по шкале 1–10 (композиция, ровность, контраст, плавность, соответствие задаче) → правки. Повторять, пока всё не 9/10. Не писать «готово», не посмотрев свежие кадры.

## Отчёт (в конце ответа, коротко)
1. Файл сцены и путь к листу кадров (`film2/snaps/sN/sheet.png`), плюс 3–5 путей к самым показательным кадрам.
2. Тайминг: таблица «время → что происходит».
3. Что не удалось или где отступил от задачи и почему.
4. Состояние первого и последнего кадра (важно для стыков).
