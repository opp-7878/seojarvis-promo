# SFX candidates — sources & measurements

All files: 48 kHz / 24-bit stereo WAV (mono sources duplicated to L/R), DC removed, leading silence trimmed (onset at −50 dB re peak, 2 ms pre-roll, 1 ms fade-in), natural tail kept down to −75 dB re peak or noise floor +6 dB, then 20 ms fade-out (5 ms for risers), **peak-normalised to −3.0 dBFS** (so relative levels between files are not the originals' — set levels in the mix).

Measurements are on the final files: LUFS-I = integrated loudness (ffmpeg ebur128; files shorter than 0.4 s read −70 because no gating block fits — use M-max instead), M-max = max momentary loudness (400 ms window), TP = true peak, Floor = RMS of last 10 ms / last 100 ms in dBFS, BW = highest frequency within 60 dB of the spectral max. No file has clipped samples (0 samples ≥ 0.9999) and all |DC| < 0.007.

**Source quality note.** Mixkit and Kenney files are the original downloads (WAV/OGG). Freesound files were made from the public HQ MP3 previews (`cdn.freesound.org/previews/…-hq.mp3`), so they are lossy and band-limited to ~16–19 kHz. For the final mix, log in to Freesound and replace them with the originals (same IDs; licence is the same).

## Rejected (examples, why)

- Zapsplat items found on Freesound — excluded per brief (attribution).
- Mixkit 1461/1462/1464 swooshes — band-limited (nothing above ~5–8 kHz), dull.
- Mixkit 1490/1492/175 — reverse-shaped whooshes cut off at the peak (better as risers).
- Mixkit 2865/2867/2869 "tones" — buzzy sawtooth beeps, not elegant. Mixkit 951/2861, Freesound 616696 (tail truncated at −30 dB), 380482 (square-wave chiptune) — rejected for success.
- Freesound 824189 "Pop in sfx" — tagged *cartoon*. 849841 — described as an *error* popup. 541993 GASP_UI_Pop_1 — gated/box-shaped envelope.
- Freesound 570754 — mechanical Cherry MX keyboard (not laptop). Mixkit 2533/2534 — keystroke tails hard-cut at −30…−40 dB. Mixkit 2537/2536, Freesound 541763 typing loops — noise floor only ~40 dB below keystrokes.
- Freesound 60013 (qubodup Whoosh), 448086, 478197, 146721 — truncated tails or static tones. Mixkit 549 — DC offset 0.012. Freesound 398638 — DC offset 0.041.
- Kenney UI Audio / most Interface Sounds — synthetic game blips with hard-cut tails.
- Pixabay — blocked from the sandbox (HTTP 403), not used. Sonniss GDC bundles — multi-GB archives, not fetched.
