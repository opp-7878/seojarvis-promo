# Полный ролик SEO Jarvis — черновой сценарий v1 (на согласование)

Дата: 22.10.2026. Длительность 1:53, 1920×1080, 60 fps, голос ElevenLabs + музыка.
Страница с раскладками кадров: `storyboard/full-film-v1/index.html` (опубликована как артефакт: https://claude.ai/artifact/9LJJirh1uyxFdHggUWnBTB). PDF для пересылки: `deliver/seojarvis-full-film-script-draft-v1.pdf`.

## Решения заказчика, на которых построен сценарий
- Начальству больше понравилось оформление **первой версии** (`film/`, превью v1): тёмная сцена бренда, окна кабинета, одна форма через весь ролик.
- Из второй версии (`film2/`, ветка `claude/epic-ritchie-wj1m8x`) заказчику понравилось, как **буква «О» → циферблат → лепестки собираются в логотип**. Остальные «фишки» v2 начальство не назвало; берём кольцо анализа, пролёт сквозь кольцо, 3D-наклон кабинета с надписью, наезд на одну карточку.
- **Без стеклянных полупрозрачных вставок.** Окна — как в кабинете, тонкая рамка, тень.
- **Кабинет — в светлой теме** (просьба заказчика): белые окна на тёмной сцене бренда, как в первой версии. В демо-кабинете тема включается `localStorage['lkj-theme']='light'`.
- Шрифт интереснее Inter: предложены Unbounded (советую), Geologica, Tektur, Manrope. Внутри окон кабинета — Inter, как в настоящем кабинете.
- Кабинет взят из выгрузки, которую прислал заказчик (`research/cabinet-demo.html`, демо-данные, можно менять). Снимки всех экранов в светлой теме — `research/cabinet-screens/` (тёмные — `research/cabinet-screens/dark/`). Свежее описание продукта — `brief/04-product-description-oct20.txt`.
