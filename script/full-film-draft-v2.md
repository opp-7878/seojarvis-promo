## Правки начальника и решения
1. Начало «Отчёт раз в месяц?» убрано. Открываемся фразой «Всё для продвижения — в одном кабинете» (слова начальника; на сайте — «Всё для роста — в одном кабинете»), дальше по модулям.
2. Фраза «Никаких отчётов раз в месяц или даже раз в неделю. Смотрите в любой момент времени» — **пока нигде не используем** (решение заказчика).
3. Регистрация: все способы из кабинета — телефон, почта, кнопки Яндекс ID и MAX («в 1 клик»). Mail.ru видна в кадре, голос её не называет.
4. Опрос убран.
5. Анализ: над шкалой загрузки «Jarvis собирает и готовит данные», шаги крупным списком с галочками.
6. Новый маскот (`refs/4-mascot/`, вырезанные PNG там же) — ведущий всего ролика. Промпты Google Veo — на странице раскладок (A–F). Пока считаем без видео: двигаем картинку целиком.
7. Дашборд — главный экран кабинета («Ядро поднимается в топ», 23%, 13 запросов, позиция 16), светлая тема. Скриншот начальника (тёмный) — `refs/4-mascot/boss-dashboard-dark-screenshot.jpg`.
8. 10 модулей по клику: пункт → окно раздела → обратно в пункт с галочкой → следующий.
- Шрифт и стили — с seojarvis.ru: Inter (Space Grotesk на сайте без кириллицы, русский текст там в Inter) + JetBrains Mono для статусов; цвета #1A69F0, #6BA5FF, #05070E, #FAFBFC, #3DDC84.
- Фон сцены тёмный, как в первом видео; кабинет — светлая тема, без стекла.
