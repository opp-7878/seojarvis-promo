# SEO Jarvis — рекламный моушн-ролик

Рекламный моушн-ролик для SEO Jarvis (лендинг seojarvis.ru + кабинет app.seojarvis.ru) с озвучкой ElevenLabs. Уровень — продуктовые ролики Anthropic / OpenAI.

## Статус
- [x] Анализ лендинга, экрана входа и демо кабинета (скриншоты — `research/screens/`)
- [x] Черновой сценарий превью (~30 с) — `storyboard/preview-v1.md`
- [x] Черновик озвучки — `script/voiceover-preview-v1.md`
- [ ] Согласование сценария и текста
- [ ] Скриншоты / запись реального онбординга и кабинета
- [ ] Генерация озвучки в ElevenLabs
- [ ] Сборка и рендер превью → показ руководству
- [ ] Полный ролик (60–90 с)

## Структура
| Папка | Что внутри |
|---|---|
| `brief/01-product-description.txt` | Описание продукта (исходник от команды) |
| `brief/02-motion-studio-prompt.md` | Промпт «моушн-студии»: планка качества, правила движения, петля проверки |
| `brief/03-brand-and-facts.md` | Цвета, шрифты и все тексты/цифры, которые можно ставить в кадр |
| `research/` | Скриншоты и тексты страниц, снятые 21.10.2026 |
| `storyboard/` | Раскадровки |
| `script/` | Тексты озвучки и настройки ElevenLabs |
| `refs/` | Референсы, скиллы, выбранный движок |

## Порядок работы над роликом
1. Сценарий + текст озвучки → согласование.
2. Озвучка в ElevenLabs с таймингом слов.
3. Сцены собираются кодом (HTML, кадр = функция времени), анимация ставится на слова.
4. Черновой рендер в половинном размере → лист кадров → оценка каждой сцены 1–10 → правки, пока всё не 9+.
5. Финальный рендер 1920×1080, 60 fps, звук −14 LUFS.

## Правила
- В кадре только реальные тексты и цифры из `brief/03-brand-and-facts.md`. Демо-данные — на домене example.ru.
- Никаких выдуманных отзывов и чужих логотипов без разрешения.
