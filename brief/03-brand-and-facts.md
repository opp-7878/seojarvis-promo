# Бренд и факты для кадра

Снято с живых страниц 21.10.2026 (скриншоты — в `research/screens/`).
Правило: в кадре только то, что есть здесь. Новые цифры — только после подтверждения.

## Цвета

| Роль | Значение | Где видно |
|---|---|---|
| Фон лендинга | `#000000` + синее радиальное свечение, тонкие вертикальные линии | seojarvis.ru, первый экран |
| Акцент (кнопки, активные элементы) | `#1A69F0` | «Попробовать бесплатно», «Подключить сайт» |
| Фон кабинета (тёмная тема) | тёмно-синий, почти чёрный; карточки с тонкой рамкой | демо кабинета на лендинге |
| Рост / успех | зелёный (`+3 за месяц`, позиции в топ-10) | кабинет |
| «Это вы» / внимание | жёлто-оранжевый (индекс здоровья 53, доля в нише, строка example.ru) | кабинет |
| Проблема | красный (маркеры в «Индексе здоровья», кнопка удаления) | кабинет |
| Экран входа | белый справа, синяя градиентная панель слева | app.seojarvis.ru/login |

Радиус кнопок — 12 px. Логотип — синий скруглённый квадрат с белым знаком-«вихрем», рядом слово «Jarvis» / «SEO Jarvis».

## Шрифты

- Заголовки лендинга — **Space Grotesk**, 600, трекинг ≈ −1.44 px на 48 px (плотный).
- Текст лендинга — **Inter Variable**.
- Кабинет — **Inter**.

Оба шрифта бесплатные (OFL), их можно встроить в ролик.

## Тексты и цифры, которые можно ставить в кадр

С лендинга:
- «Платформа вместо агентства»
- «Продвижение сайтов в ТОП Яндекса»
- «Всегда знаем, где сейчас находятся ваши конкуренты и как их обойти»
- «Всё продвижение — как на ладони»
- «Всё для роста — в одном кабинете»
- «120+ проверок скорости, индексации и разметки»
- «Позиции в Яндексе и Google обновляются ежедневно»
- «Цена известна заранее»

Из описания продукта:
- «SEO на автопилоте»
- «Пять дней реального продвижения бесплатно, без карты»
- Онбординг — одно поле: домен сайта; дальше шесть шагов без участия человека: ниша → семантическое ядро → приоритизация → ежедневный съём позиций → технический аудит → рекомендации и отчёт
- Скоринг аудита 0–100
- Один вход через Яндекс ID → Метрика + Вебмастер

Из экрана регистрации:
- «Создание аккаунта. Заполните данные — это займёт минуту»
- Поля: Имя / Email или телефон / Пароль → «Создать аккаунт»; вход также через Яндекс ID и MAX

Демо кабинета (домен **example.ru**, это пример, не клиент):
- Позиций в Топ-3: **8** (+3 за месяц) · в Топ-10: **24** (+6) · Видимость: **7.4%** (+1.2%) · Доля в нише: **2.1%** (цель 8%)
- Индекс здоровья сайта: **53** из 100
- Ключевые запросы: «стоматология москва» — 3 (+4), «лечение зубов недорого» — 6 (+2), «удаление зуба цена» — 10 (+1)
- Доля рынка: competitor1.ru 31%, leader-site.ru 19%, best-niche.ru 12%, example.ru 7.4%, rival3.ru 5%
- Меню: Дашборд, Проекты, Яндекс.Карты, Бонусы, Оплата, Партнёрам, Поддержка, Обучение
- Вкладки проекта: Обзор, Отчёт по позициям, Конкуренты, Ссылки, Анализ SEO трафика

## Не ставить в кадр без подтверждения

- Отзывы с экрана входа («Вышли в топ-10 за 3 месяца» и др.) — нужно подтверждение, что они настоящие.
- Логотипы Яндекса, Google, Keys.so, eLama и сервисов-партнёров — только с разрешения.
- Цены тарифов — для превью не нужны; в полном ролике — сверить перед рендером.
