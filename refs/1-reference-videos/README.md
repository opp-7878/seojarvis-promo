# Ролики-референсы

Ролики из папки «Референсы моушен роликов», которые нравятся по стилю: фон, движение, типографика, переходы.

- Можно добавить короткую заметку в `notes.md`: что именно нравится в каждом ролике (например, «01.mp4 — фон и плашки», «02.mp4 — переходы под музыку»).
- Файлы больше 25 МБ — ссылкой в `links.md`.
