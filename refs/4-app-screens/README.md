# Скриншоты приложения app.seojarvis.ru

Интерфейс перерисовывается по ним точно, поэтому лучше крупные скриншоты (Retina / полный экран браузера).
Назови файлы по порядку:

- `01-login.png` — вход / регистрация
- `02-onboarding.png` — онбординг (intro и вопросы)
- `03-site-url.png` — ввод ссылки на сайт
- `04-analysis.png` — процесс анализа / загрузка
- `05-result.png` — результат анализа
- `06-section.png` — раздел, который показываем в финале

Если есть запись экрана, как проходишь эти шаги, — тоже клади (она покажет реальные анимации и загрузки).
Цифры в ролике будут только те, что есть на скриншотах или в сценарии.
