## Музыка
Опознана через Shazam: **QMIIR & Akhmedov — «HUEGO (Super Slowed)»** (EP «HUEGO (Remix)», Sketch Music, 2025, 2:12). В ролике Gemini звучит отрезок с 64.5 с трека.
Полной версии в открытом доступе нет; 30-секундное превью Apple Music (AAC 256 кбит/с) содержит весь отрезок из референса и ещё 16 с. Из него по тактам собрана 30-секундная редакция (`film2/tools/audio.py`).
**Лицензия:** трек коммерческий. Для публикации рекламы нужна лицензия правообладателя (лейбл Sketch Music) или покупка через сервис синхронизации.
