# Материалы для ролика SEOJarvis

Загрузка через GitHub: открой нужную папку → **Add file → Upload files** → перетащи файлы → **Commit changes**.
Через сайт GitHub проходят файлы до 25 МБ. Если файл больше — положи его на Яндекс.Диск / Google Drive
с открытым доступом и вставь ссылку в `links.md` той же папки (кнопка **Add file → Create new file**).

| Папка | Что положить | Обязательно |
|---|---|---|
| `1-reference-videos/` | Ролики-референсы, которые нравятся по стилю | да |
| `2-music/` | Ролик с музыкой `fa4d47f63f01a836d61d29d2afa4f77b.mp4` + название трека, если знаешь | да |
| `3-old-video/` | Прошлый ролик SEOJarvis (MP4) и/или его сценарий с точными текстами | да |
| `4-app-screens/` | Скриншоты приложения app.seojarvis.ru по шагам | да |
| `5-brand/` | Логотип (SVG/PNG), фирменные шрифты, цвета — если есть | по желанию |

Подробности — в README внутри каждой папки.
