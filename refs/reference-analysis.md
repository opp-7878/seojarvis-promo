Ограничение: у OpenAI видели только ключевые кадры, не движение. Выводы про их ритм — осторожные.

## Что увидели

**Anthropic (главный ориентир для нас — у них, как и у нас, продукт = интерфейс):**
1. **Один элемент на кадр, много воздуха.** Окно приложения занимает 40–60% кадра на спокойном фоне, вокруг пусто. Никакой «стены» интерфейса.
2. **Экстремальный крупный план.** Камера влетает в одну ячейку таблицы, одно поле ввода, одну реплику — и этот элемент становится героем (claude12 0:06, claude04 0:04).
3. **Подсветка изменения.** В ячейке, где меняется цифра, проходит мягкая цветная «волна» — глаз сразу находит, что изменилось (claude12 0:06–0:07).
4. **Статус крупно, с бегущим бликом по тексту:** «Filling field…», «Checking formatting…», «Finding tools…» — отдельный кадр, текст по центру (claude12 0:04, claude01 0:03).
5. **Курсор — простой системный, кликает по сегментному переключателю** (Chat → Cowork), ползунок перетекает (claude14 0:00–0:03).
6. **Логотип рождается из точки** и растёт в знак, потом рядом выезжает заголовок (claude14 0:04–0:05).
7. **Ритм:** одна мысль 1.5–3 с. Переходы — наезды камеры и **жёсткие склейки точно на смене мысли**. Шторок и затемнений нет.
8. Финальная плашка — очень простая: знак + одна строка.

**OpenAI:**
1. Титры — крупный чистый текст на однотонном фоне или поверх фото («Build dashboards in seconds with ChatGPT Work», «Introducing ChatGPT for Microsoft Word»).
2. Много живых съёмок людей — **нам не подходит** (нет съёмок, превью из одного интерфейса).
3. Слова, разбросанные по кадру и собирающиеся во фразу («Sometimes words aren't enough»).

**Cheerful (эталон скилла):**
1. Заголовок по словам → поле ввода с набором текста → «стена» карточек → огромная цифра-одометр по центру → логотипы клиентов по одному → вордмарк.
2. Смена сцены каждые 2–3 с, одна форма почти не режется.

## Что сознательно не берём
- **Тёплую бежевую палитру, засечки и «точечные облака» Anthropic** — это их бренд. У Jarvis свой: чёрный фон с синим свечением и вертикальными линиями (с лендинга), синий `#1A69F0`, Inter.
- **Живые съёмки людей (OpenAI)** — их нет, и в превью они не нужны.
- **Ноутбук/телефон-мокапы** — у нас один веб-кабинет, мокап отнимет место у интерфейса. Окна кабинета показываем «голыми» карточками.
- **Логотипы клиентов «бум-бум» (Cheerful)** — у нас нет подтверждённых клиентов; отложено до полного ролика.

## Итог для стиля Jarvis
Тёмная «сцена» бренда (как первый экран лендинга) + светлые окна реального кабинета, парящие на ней с мягкой многослойной тенью. Один герой в кадре, камера влетает в важное, курсор ведёт действие, одна форма перетекает через весь ролик, редкие точные склейки. Пик — когда шесть шагов анализа раскрываются в живой кабинет.
