# Ролик v2 — как делался и что правили

## 1. Анализ
- 8 роликов заказчика разобраны по листам кадров (`refs/sheets-v2/`), выводы — `refs/reference-analysis-v2.md`.
- prompt-motion.com: 236 примеров, полезны ~10 длинных промптов. Взяли приёмы «одна форма через все состояния», «проход сквозь букву О», «дашборд под углом рядом с крупной подписью» (Taxtello), правила «никогда не зумить туда-обратно подряд», «держать стоящий текст резким».
- Музыка опознана через Shazam: QMIIR & Akhmedov — «HUEGO (Super Slowed)». Полной версии в открытом доступе нет, есть 30-секундное превью Apple Music, в нём весь кусок из референса + 16 с. Темп 98.2 BPM, такт 2.445 с.
- Шрифт: сравнены Google Sans, Onest, Manrope, Golos Text, Inter Tight, Wix Madefor Display, Geologica. Выбран Google Sans (шрифт ролика Gemini, OFL). Его «О» — почти идеальный круг, поэтому буква может стать кольцом без шва.
- Звуки: 31 кандидат, лицензии CC0 / Mixkit, проверены замерами (клиппинг, шум, полоса). Список и лицензии — `film2/audio/sfx_candidates/SOURCES.md`.

## 2. Музыкальная редакция
Монтаж по тактам: вступление ×2 → удар баса → нарастание → дроп → затишье → удар и затухание. Склейки сдвинуты на 12 мс до удара, чтобы не было двойной атаки. Проверка на щелчки — сравнение резких перепадов на стыках с исходником: все стыки совпадают с исходником.
