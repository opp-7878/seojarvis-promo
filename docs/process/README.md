# Как делался превью-ролик — по шагам, со скриншотами

Каждый шаг — лист кадров с таймкодами, который смотрелся перед правками. Так устроена петля проверки из `brief/02-motion-studio-prompt.md`: отрендерить → собрать лист кадров → найти худшие места → исправить → снова смотреть.
