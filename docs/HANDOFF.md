## 4. Ключевые решения и почему
| Решение | Почему |
|---|---|
| Ролик собирается **кодом**: HTML, каждый кадр = функция `seek(t)`, рендер Playwright кадр за кадром → ffmpeg | По скиллам product-launch-motion и claude-motion-design: детерминированно, бесплатно, любую сцену можно поправить отдельно. Remotion не брали: у коммерческой компании от 4 человек нужна платная лицензия |
| **Одна форма без склеек** перетекает через весь ролик; содержимое меняется через короткое размытие | Главный приём скилла product-launch-motion и роликов Anthropic |
| Тёмная «сцена» бренда (чёрный, синее свечение, вертикальные линии — как первый экран лендинга) + **светлые окна реального кабинета** | Лендинг тёмный, кабинет светлый; Anthropic показывает «голые» окна на спокойном фоне |
| Шрифт **Inter** (не Space Grotesk с лендинга) | В Space Grotesk нет кириллицы; на лендинге русские заголовки и так падают в Inter |
| Цвет акцента `#1A69F0`, логотип — SVG с app.seojarvis.ru | Сняты с живых страниц |
| Демо-данные на **example.ru**, ниша «стоматология, Москва» | Как в демо на лендинге; заказчик разрешил любые данные для превью |
| Музыка **Mixkit «Opalescent» (№720)**, старт трека с 2.759 с | 123 BPM, тихое вступление и бит на 22.909 с трека — бит попадает ровно на пик ролика 20.15 с. Лицензия Mixkit разрешает коммерческое видео |
| Звуки интерфейса синтезированы (numpy) и поставлены по меткам из анимации (`window.CUES`) | Клики, набор текста, «вжухи» переходов, тики шагов по нотам, удар на пике |
| Голос «как J.A.R.V.I.S.» — через Voice Design по описанию, **не клонирование** | ElevenLabs запрещает клонировать голос без согласия; для рекламы ещё и юридический риск |

## 6. Как работать с исходником
```bash
cd film
npm i
python3 -m http.server 8765 --bind 127.0.0.1 &          # страница ролика: http://127.0.0.1:8765/index.html
node tools/snap.mjs snaps/x 0.5 0 5 10 20.15 25           # стоп-кадры + snaps/x/sheet.png
node tools/render.mjs --out out/draft.mp4 --fps 30 --scale 0.5    # черновик ~5 мин
tools/render_all.sh 3                                     # финал 1080p60, 3 подкадра, 4 потока, ~25 мин
node tools/cues.mjs && python3 tools/audio.py             # звук по меткам анимации
tools/master.sh audio/mix_novo.wav ../deliver/preview.mp4 # −14 LUFS + склейка с видео
```
- Все тайминги — объект `T` в начале `film/film.js`. Состояния формы — `ST`, камера — вызовы `cam(...)`, курсор — `curTo(...)`, смены экранов — массив `PANELS`.
- Координаты кнопок и полей для курсора и камеры **измеряются автоматически** при загрузке (`measure()`), поэтому вёрстку можно менять.
- Перед правками смотреть листы кадров, после правок — снова. Не писать «исправлено», пока не перерендерил и не посмотрел.
